BrainBuffs is a collaborative learning and knowledge‑sharing community designed to help learners, professionals, and enthusiasts sharpen their skills through interactive resources, discussions, and projects. It’s a hub for curiosity, creativity, and continuous growth.

🚀 Features
Interactive Learning Modules – Bite‑sized lessons and challenges.

Community Discussions – Share insights, ask questions, and collaborate.

Quizzes & Flashcards – Reinforce knowledge with gamified learning.

Project Showcases – Highlight community creations and innovations.

Resource Library – Curated articles, tutorials, and guides.

🛠️ Tech Stack
Frontend: React / Next.js, Tailwind CSS

Backend: Node.js, Express

Database: MongoDB

Deployment: AWS / Vercel
